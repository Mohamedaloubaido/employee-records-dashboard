# Employee Records Dashboard

A clean, responsive employee management dashboard built as a portfolio project with React, TypeScript, and Vite.

## Features

- Employee directory with realistic sample data
- Search across names, emails, roles, and departments
- Filter by employee status
- Workforce summary cards
- Add a sample employee record
- Export filtered records to CSV
- Responsive layout for desktop and mobile

## Tech Stack

- React
- TypeScript
- Vite
- Lucide React
- CSS

## Getting Started

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite in your browser.

## Production Build

```bash
npm run build
npm run preview
```
